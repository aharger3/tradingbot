# G83 — dark theme, every HTML page

Austin, 2026-08-30: "I like dark artifacts." Scope was three targets. All three were
checked; all three already carry a spec-correct dark theme (light palette on bare
`:root`, overridden under both `@media (prefers-color-scheme: dark){:root:not([data-theme="light"])}`
and `:root[data-theme="dark"]`, explicit `body{background:var(--bg)}`). No code change
was needed — this doc is the verification record plus the one place each palette lives,
so the next page that needs a dark theme copies from here instead of re-deriving it.

## Palette lives in ONE place per surface family

Two page families exist in this repo, each with its own single CSS-variable block:

1. **`research/probe_page.py::CSS`** — the shared homework shell (masthead, sticky
   progress bar, chips, cards) *and* the chart classes `probe_chart.py` renders into
   (`.chart .up/.dn/.wk/.bd`, `.chart .lvl-pd/pm/or/hl`, `.chart .entry/.stopl`).
   Every page built on `probe_page.shell()` — the ballot decks, the autopsies,
   `g75_deck2.html`, OMEN Test 1 — inherits this one block. `g75_deck2_build.py`'s
   `EXTRA_CSS` (the "no minute on a yes card" nag banner) adds two rules and both
   reference `var(--surface-2)` / `var(--stop)` / `var(--rule)` / `var(--shadow)` from
   the same block — no new hex anywhere.

   ```
   --bg --surface --surface-2          page ground / card / recessed panel
   --ink --ink-2 --ink-3               text, most to least prominent
   --rule --rule-2                     hairlines, borders
   --accent --accent-ink --accent-soft accent colour + its own readable ink + soft fill
   --up --dn                           candle body/wick colour (green/red)
   --entry --stop                      trade entry line / stop line (amber / red-brown)
   --lvl-pd --lvl-pm --lvl-or --lvl-hl PDH/PDL, PMH/PML, ORH/ORL, HOD/LOD level lines
   --shadow                            card drop shadow
   ```

2. **`research/g82_artifact_cleanup_build.py`** (generates `omen-71-verdict.html`) —
   a status/verdict sheet, not a chart page, so it has its own smaller block tuned for
   gate pills and a before/after table rather than candles:

   ```
   --bg --surface --surface2 --line    page ground / card / recessed panel / hairline
   --ink --muted --faint                text, most to least prominent
   --accent --accent-soft               accent + its soft fill
   --met --met-soft                     gate MET (green)
   --miss --miss-soft                   gate MISSED (red)
   --warn --warn-soft                   gate borderline (amber)
   ```

Neither file has a stray hex colour outside its `:root` block (checked with
`grep -n "#[0-9a-fA-F]\{3,6\}"` across both plus `probe_chart.py` and
`g75_deck2_build.py` — every hit is one of the two palettes above, plus one
pre-existing `color:#fff` on the veto-chip's pressed state, which is white text
on the saturated `--stop` red in both themes and stays readable in both).

## Eye-check (by description — no browser in this environment)

**Candle charts** (`probe_chart.py` output, dark mode): ground `#0d1211` (near-black,
slight green cast). Up candles `#48b57c` (bright green), down candles `#e07068`
(warm coral-red) — both bodies and wicks share the class colour, so a wick is never
harder to see than its own body. Gridlines `var(--rule)` = `#25322f`, a dim
blue-green a few steps above the ground — visible as a faint 15-minute reference,
not a distraction; this replaces what would have been a mid-grey that disappears on
black. The six level lines are dashed (`stroke-dasharray:5 4`) so they read as
"reference," not price action, and each has its own hue: PDH/PDL blue `#8fa2dc`,
PMH/PML violet `#bb92d1`, ORH/ORL teal `#6dbcb0`, HOD/LOD tan-orange `#e09a5c` — all
four sit clearly apart from the green/red candles and from each other. Entry line
`#e0a340` (bright gold) and stop line `#d47a70` (dusty red) are solid, not dashed,
so a trade marking never gets mistaken for a level; entry and HOD/LOD land in the
same warm-orange family but differ in saturation (entry: punchy gold, HOD/LOD: muted
tan) and in dash pattern, which is the same disambiguator the light theme already
relies on.

**Homework shell** (`probe_page.py`): card surface `#151d1c` one step up from the
`#0d1211` ground, so cards read as raised panels rather than flat text on black.
Chips are outlined (`--rule-2`) until picked, then filled solid `--accent` (`#54cfbe`,
a bright teal) with dark ink text (`#07201d`) for contrast — a picked chip cannot be
confused with an unpicked one at a glance. The veto question's picked state swaps to
`--stop` (`#d47a70`) with white text, same distinction rule as light mode.

**Verdict sheet** (`omen-71-verdict.html`): ground `#0D1018`, gate pills use
`--met`/`--miss`/`--warn` (`#3FBF8C` green / `#F0705E` red / `#DDA83B` amber) each
paired with its own soft fill (`#14301F` / `#331A18` / `#2E2413`) so a MET pill, a
MISS pill and a borderline pill are distinguishable by fill colour before the text
is even read.
